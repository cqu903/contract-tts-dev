# v1 单实例部署（进程内锁与本地磁盘缓存）

对外服务 v1 以**单实例容器、单 Uvicorn worker**运行：按需合成 + 内容寻址的**本地持久化 volume**缓存（`cache/*.{wav,mp3}`）+ **进程内** per-key 锁（`app.py` 的 `_locks` dict）。

**理由**：探针已是单实例；进程内锁保证「同一 contract_id 的并发请求只合成一次」、本地盘保证缓存一致——这些都是单进程前提下的最简实现。v1 不引入分布式依赖。

**约束**：`_locks` 仅在单进程内有效。水平扩展到多实例会使 per-key 去重失效（并发击穿、重复合成）、本地缓存分叉。将来要多实例，须把锁换成分布式（如 Redis）+ 缓存换成共享存储，并让原文存储外挂。
